3. MATHEMATICAL & PHYSICAL PRINCIPLES
-------------------------------------------------------------------------------

A. Coordinate Frame Transformations
------------------------------------
1. Earth-Centered Inertial (ECI - TEME): Space-fixed coordinate frame centered 
   at Earth's center of mass.
2. Radial-Transverse-Normal (RTN): Satellite-centered local orbital frame.
   - Radial (R): Along position vector r from Earth center.
   - Transverse (T): Perpendicular to R in orbital plane (along velocity v).
   - Normal (N): Along orbital angular momentum vector h = r x v.

3. ECI Rotation Matrix:
   R_sat = [ u_R  u_T  u_N ]
   C_ECI = R_sat * C_RTN * R_sat^T

B. Foster's 2D Encounter Plane (b-Plane) Projection
---------------------------------------------------
1. Relative Velocity at TCA:
   v_rel = v_sat - v_deb

2. b-Plane Orthonormal Basis Vector Construction:
   u_y = v_rel / ||v_rel||                  (Parallel to relative velocity)
   u_x = (r_rel - (r_rel · u_y) u_y) / ||...||  (Projected relative position)
   u_z = u_x x u_y                         (Completes right-handed system)

3. 3x2 Projection Matrix P:
   P = [ u_x  u_z ]

4. 2D Relative Covariance Matrix:
   C_2D = P^T * (C_sat_ECI + C_deb_ECI) * P

C. Infinitesimal Analytical Collision Probability (Pc)
------------------------------------------------------
The collision probability over a circular Hard-Body Radius (HBR) R_HBR:
   Pc ≈ [ R_HBR^2 / (2 * sqrt(det(C_2D))) ] * exp( -0.5 * d^2 * C_2D_inv[0,0] )
where d is the relative miss distance at TCA.

D. High-Fidelity Perturbed Numerical Physics (RK4 Integrator)
-------------------------------------------------------------
State integration X = [r, v]^T via 4th-Order Runge-Kutta:
   a_total = a_grav + a_J2 + a_drag

1. Central Keplerian Gravity:
   a_grav = -μ * r / ||r||^3

2. J2 Earth Oblateness Perturbation:
   a_J2 = (3/2) * (J2 * μ * R_E^2 / r^5) * [ (5 * (z/r)^2 - 1) r - 2 z k_hat ]

3. Atmospheric Drag Acceleration:
   a_drag = -0.5 * ρ(h) * C_d * (A/m) * ||v_rel|| * v_rel
   ρ(h) = ρ_0 * exp( -(h - h_0) / H )

E. 3D Spacecraft CAD Mesh Projection & Monte Carlo Quadrature
------------------------------------------------------------
1. Spacecraft Geometry:
   - Central Bus: 3.0m x 2.0m x 2.0m cuboid
   - Solar Panels: Two arrays (0.2m x 2.0m x 5.0m) along Normal axis

2. 3D Body to 2D b-Plane Projection:
   v_b = P^T * R_sat * v_body

3. 2D Convex Hull: Graham Scan algorithm over projected vertices.

4. Monte Carlo Quadrature Integration:
   Pc_mesh ≈ (Area_bbox / N) * Σ_{k ∈ Hull} PDF_2D(x_k, z_k)
   PDF_2D(x, z) = [ 1 / (2 * π * sqrt(det(C_2D))) ] * exp( -0.5 * [x, z] C_2D^-1 [x, z]^T )

F. Unscented Kalman Filter (UKF) State Estimation
------------------------------------------------
1. Sigma Point Generation (2n + 1 points):
   χ_0 = x_hat
   χ_i = x_hat + [ sqrt((n + λ) Σ) ]_i      for i = 1..n
   χ_i = x_hat - [ sqrt((n + λ) Σ) ]_{i-n}  for i = n+1..2n

2. Non-linear State Propagation:
   γ_i = f(χ_i, dt)
   x_bar = Σ W_m^(i) γ_i
   P_bar = Σ W_c^(i) (γ_i - x_bar)(γ_i - x_bar)^T + Q

G. Reinforcement Learning Evasive Maneuver Optimization
-------------------------------------------------------
1. PPO Objective Function:
   L^CLIP(θ) = E_t [ min( r_t(θ) A_t, clip(r_t(θ), 1-ε, 1+ε) A_t ) ]

2. Dynamic Lead-Time Delta-V Savings:
   ΔV_required ∝ 1 / (TCA - t_burn)
   Scheduling maneuver at t = TCA - 120 min allows orbital drift accumulation,
   reducing Delta-V requirements by up to 80% compared to immediate burns.
